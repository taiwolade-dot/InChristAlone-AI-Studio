# InChristAlone AI Studio Development Guide

Project:
InChristAlone AI Studio

Objective:
Build a Christian AI ministry platform enabling:
- Churches
- Ministries
- Fellowship groups
- Pastors
- Individuals

Core capabilities:
- AI Ministry Assistant
- Church database management
- Pastor and member intelligence
- AI content generation
- Bible Study Outline generation
- AI flyer generation
- Church websites
- Quiz competitions
- Ministry analytics

Current architecture:
- Flask application
- SQLAlchemy database
- Modular blueprints
- AI integrations:
  - fal.ai
  - Anthropic
  - Gemini

Development rules:
1. Do not remove existing working features.
2. Create backups before major edits.
3. Run python -m py_compile after Python changes.
4. Commit changes with meaningful messages.
5. Preserve AI Ministry Intelligence features.
6. Maintain Christian ministry branding:
   Primary color: #1a2a6c
   Accent color: #d4af37
